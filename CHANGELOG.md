# Changelog

What's new in each version. The app shows the newest entries once after an
update, and the release workflow uses the same text for the GitHub release.
Keep one `## <version>` heading per release and plain `- ` bullets under it.

## 1.0.2

- **A fresh look**: the app now wears the IGLAcademy colours, coral for buttons and highlights and teal for your progress.
- **Quizzes are called quizzes**: quiz lessons show as "Quiz" with a checklist icon in the course outline.
- **What's new**: after an update, a short summary like this one shows what changed.

## 1.0.1

- **Lecture quizzes run in the app**: quizzes inside a course open as a real quiz instead of a blank page. Each answer is checked instantly, with an explanation of why the right option is correct and why the others are wrong. Finishing the quiz completes the lesson.
- **Skip the last question**: the final question of a quiz or practice exam can be skipped, like all the others.

## 1.0.0

- **Course import**: pick a folder; subfolders become sections and videos become lessons. Your files are never moved or changed.
- **Video player**: speed control, resume where you left off, subtitles, picture-in-picture, A–B loop, bookmarks and keyboard shortcuts (press `?`).
- **Notes**: Markdown notes per lesson with clickable video timestamps.
- **Quizzes and flashcards**: course quizzes that resume after closing, with mistakes turned into spaced-repetition flashcards.
- **Practice exams**: HTML practice tests in Practice or timed Exam mode, with score history and weak-topic analysis.
- **Progress**: watch time, a daily goal, a study streak and per-course progress.
- **Search**: Ctrl+K finds courses, sections, lessons, notes and exams.
- **Backups**: automatic database backups plus JSON export and import.
- **Automatic updates**: new versions download in the background and install on restart.
